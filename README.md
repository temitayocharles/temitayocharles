## Engineering approach

- **Evidence before conclusions:** verify runtime state rather than treating a merge as completion.
- **Automation with controls:** convert repetitive procedures into bounded, observable workflows.
- **Source authority matters:** keep canonical source, deployment authority, and mirrors explicit.
- **Design for day two:** observability, recovery, rollback, runbooks, and ownership are part of delivery.
- **Security boundaries stay visible:** secrets and privileged actions remain separated from diagnostic output.
